🌿 Green Earth – Environmental Awareness Website

🌍 Green Earth is a responsive and eco-friendly website dedicated to promoting sustainable living, environmental protection, and climate awareness.
This project is built with pure HTML, CSS, and JavaScript, focusing on clean design and user experience.

✨ Features

✅ Responsive navigation bar
✅ Mobile-friendly design (480px optimized) 📱
✅ Hero section with call-to-action buttons
✅ Mission, Projects, Resources & Contact sections
✅ Clean UI with eco-themed emojis 🌱
✅ Beginner-friendly code structure

🛠️ Technologies Used

.🌐 HTML5 – Structure

.🎨 CSS3 – Styling & responsiveness

.⚙️ JavaScript – Interactivity

.⭐ Font Awesome – Icons
